## B. 광고 판매(현금) — 이번에 만든 흐름을 켜기 전에

| 확인할 것 | 메모 |
| --- | --- |
| 사업자 등록, 업종에 광고대행·온라인 광고 포함 여부 | 세금계산서 발행 |
| 통신판매업 신고 | 온라인으로 신청받고 돈을 받으면 해당될 수 있다 |
| 광고 심사 기준과 금지 업종 | 표시광고법(허위·과장), 청소년보호법(유해 업종), 도박·성인·대부·의약품 등. 관리자 화면에서 거절할 수 있게 해 두었다 |
| 광고 표시 | 광고 화면에는 `광고` 표시가 있다. 링크 카드에도 있다 |
| 환불 규정 | 약관 초안: 시작 전 취소 전액, 운영자 사정으로 송출이 멈추면 남은 날만큼. 법무 검토 필요 |
| 수치 표현 | 리포트는 '게임이 센 수'다. '노출 보장', '공식 노출'이라는 말을 쓰지 않는다 |
| 상표·초상 | 팬 생일 광고에 아이돌 이름·사진이 들어간다. 소속사 정책, 초상권. 사진은 운영자 승인 뒤에만 송출된다 |
| 카드 결제(PG) | 처음에는 계좌이체·세금계산서로 수동 처리. PG(토스페이먼츠 등)는 심사 뒤. 코드에 결제 SDK는 없다 |

## C. 유료 코인 충전 — 하기 전에 반드시

이 게임의 구조상 위험이 큰 부분이라 순서를 지킨다.

1. **지표 관문**: 예전 메모의 기준(다음 날 재방문 35%, 7일 15%, 30일 6%, 초대 1회당 신규 0.3)을 `/rt/admin/stats`로 확인.
2. **게임물 등급분류**(게임산업진흥법): 웹게임으로 유료 아이템을 팔 때 등급분류 대상인지, 어느 등급인지.
3. **사행성 판단**(게임산업진흥법의 사행성 게임물, 경품·환전 금지):
   - 코인 경매(점령·빼앗기)와 **코인 상금 추첨**이 있다. 코인을 현금으로 살 수 있게 되면 '우연으로 재산상 이익'으로 볼 여지가 생긴다. 충전을 열기 전에 추첨을 없애거나 상금을 코인이 아닌 꾸미기로 바꾸는 것을 권한다.
   - 코인을 현금으로 바꾸는 길은 지금도 없고 앞으로도 만들지 않는다.
   - `광고주에게 코인 보내기`(이용자 간 코인 이동)가 환전·선불전자지급수단 판단에 영향을 주는지 확인(전자금융거래법).
4. **확률형 아이템 정보 공개**: 돈으로 사는 무작위 상품이 생기면 확률 공개 의무. 지금 상점은 무작위가 없다. 앞으로도 뽑기는 만들지 않는 것을 권한다.
5. **청소년 결제**: 만 14세 미만·청소년의 결제 한도와 법정대리인 동의. 손님 플레이의 연령 확인.
6. **청약철회·환불**(전자상거래법의 디지털콘텐츠): 쓰지 않은 코인 7일 안 환불, 사용한 코인은 철회 제한을 구매 전에 고지.
7. **약관·처리방침 고치기**: 지금 약관은 "코인은 현금으로 바꾸지 않는다", "유료 서비스" 문장이 있다. 충전을 열 때 유료 서비스 조항, 결제대행 위탁, 환불 규정을 함께 넣는다.
8. **PG 계약**과 결제 검증: 서버에서 결제 승인 확인(금액 위변조 방지) 뒤 코인 지급, 중복 지급 방지(주문 번호 단일 사용), 취소 시 회수.

## D. 권장 순서

1. 지금: A를 끝내고 광고 판매를 수동 결제로 연다(`ADS_ON=1`, `ADS_PRICES`).
2. 광고 매출과 지표를 보며 코인 꾸미기 상점(코인 전용)으로 소모처를 키운다.
3. 관문을 넘고 C를 모두 확인한 뒤에만 유료 코인 충전을 설계한다.
