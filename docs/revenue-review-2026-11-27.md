# 비게임 구조의 수익모델 다시 보기 (2026-11-27)

주인이 "비게임 현재 구조로 수익모델을 다시 한번 점검해 보자. 고도화하면 사람들이 좋아할 포인트를 찾을 수 있을 것 같다"고 했다. 그 전에 "게임 요소를 다 빼니 전광판에 걸고 싶은 욕구가 안 생긴다. 사람들은 메인 전광판에 내 것을 걸고 싶어 해야 한다. 선물 영상은 퀄리티가 너무 떨어진다"고 했다.

만든 방식: Opus 작업자 둘이 읽기만으로 일했다(코드에서 돈과 욕구가 붙을 수 있는 곳 / 바깥 사례 조사). 본 세션이 핵심 사실(R2 연결 없음, 선물 가격표의 약속)을 코드에서 다시 확인하고 이 문서로 묶었다. 코드는 바꾸지 않았다. 바탕 계획은 `reports/위시보드 비게임 수익 극대화 전략.md`(자리·시간·증거를 판다)이고, 이 문서는 그 계획이 놓친 것만 적는다. 법 이야기는 공개 자료 정리이고 변호사 의견이 아니다.

## 1. 한 줄 결론

팔 상품의 방향(자리·시간·증거)은 맞다. 지금 안 팔릴 이유는 상품이 아니라 **"아무도 모르고, 남는 것이 초라하다"**는 데 있다. 선물 전광판은 272자리 가운데 작은 거리 화면 하나에 9초씩 돌고, 걸려도 광장에 알림이 없고, 받는 사람은 소리 없는 2D 그림 영상을 받는다. 경쟁 없이도 욕구를 만드는 길은 **정해진 1분, 모두가 보는 자리, 자랑할 만한 증거** 셋이다.

## 2. 지금 코드가 보여 주는 문제 (코드 위치는 작업자 보고, 본 세션이 두 곳을 다시 봤다)

| 문제 | 사실 |
| --- | --- |
| 받는 사람은 3D가 아니라 2D 영상을 본다 | `wrangler.jsonc`에 R2(`MEDIA`) 연결이 없다(본 세션 확인). 그래서 휴대폰으로 녹화한 3D 영상은 만든 사람 기기에만 있고, 받는 사람 페이지는 `giftfilm.js`의 2D 캔버스 영상(상자 거리, 네온 사각형, 2D 동물)을 튼다 |
| 3D 녹화도 화질 한계가 있다 | 화면에 보이는 세로 기둥을 720×1280, 30fps, 1.8Mbps로 담는다. 화면 배율 상한 1.25~1.75, 느리면 0.75로 떨어진다. 전광판 글자는 512×288 그림이다. 소리가 없다. 모든 프레임에 `WISH BOARD · 무료` |
| 가격표가 지킬 수 없는 것을 적는다 | 1단 `크게 걸기`의 "큰 화면에 24시간"(`giftrules.js:66`)인데 선물이 걸리는 곳은 거리·건물 앞 화면뿐이다(`giftrules.js:4-6`, 본 세션 확인). 3단의 9시 퍼레이드는 만들지 않았다 |
| 걸려도 아무도 모른다 | 선물이 켜질 때 속보 줄이 없다(`ui.news`가 아는 것은 전광판·토지·별·소원·환영). 받는 사람·친구에게 "지금 켜졌다"는 순간이 없다 |
| 희소성이 없다 | 한 화면 4개가 9초씩, 동시에 272개. 하트·인기로 더 보이는 일도 없다(공정하지만 귀하지 않다) |
| 남는 기록이 없다 | 선물 페이지·롤링페이퍼·영상은 그날 뒤 7일, 소원은 8일 뒤 지워진다. "내가 메인에 걸렸었다"는 기록은 팀(`tach`)만 있다 |
| 이미 있는 자랑거리가 숨어 있다 | 팀이 메인 타워에 걸려도 팀원에게 알림이 없고 사진·영상이 없다. 어제의 소원왕은 21:00에 모든 일반 전광판을 덮지만 본인은 미리 모른다. 광장 전광판에는 걸고 나면 사진·5초 영상·'신문으로 저장' 카드가 있는데 선물 전광판에는 없다 |
| 유료 가격표는 만든 사람만 본다 | 받는 사람·방문자는 유료 단을 보지 못한다. 두 번째 파는 순간(받는 순간)이 비어 있다 |

## 3. 바깥에서 찾은 것 (조사 작업자, 출처는 링크. [미확인]은 원문으로 확인 못 함)

- **경쟁 없이 '보이기'를 파는 상품이 국내에 이미 있다.** 네이트 '오늘'(2025-07)은 포털 첫 화면에 개인 메시지를 거는 상품이다. 1시간 10자리, 1자리 3만원, 하루 약 69건, 사랑 29%·축하 21% (https://m.etnews.com/20250707000009, https://byline.network/2025/08/20-465/ , 지금 가격 [미확인]).
- **야구장 전광판 생일 메시지는 정원 있는 선착순 정가다.** 다저스 25자리 160달러, 레즈 50달러(특정 경기 75달러) (https://www.mlb.com/dodgers/community/foundation/support/ribbon-board , https://www.mlb.com/reds/fans/scoreboard-messages).
- **실제 타임스퀘어 150달러 상품은 시각을 고를 수 없다**(하루 전 통보, https://timessquarebillboard.com/book-now/). 가상 광장은 "그 분"을 정확히 팔 수 있다. 이것이 우리만의 장점이다.
- **사람들은 송출보다 증거에 더 낸다.** 타임스퀘어 사진 촬영 추가가 200달러로 송출(150달러)보다 비싸다.
- **흐린 화질·워터마크는 확산을 막는다.** 인스타그램은 흐리거나 해상도가 낮거나 워터마크가 있는 릴스를 덜 추천한다고 밝혔다 (https://help.instagram.com/1525585517644948). 지금 영상은 그대로 불리하다.
- **나눠 내기**: Kudoboard는 기여자가 각자 결제(최소 5달러), 일본 Oshi-Ad는 500엔 단위. 일본 응원광고 조사에서 남이 기획한 광고에 보탠 사람의 93%가 다시 하겠다고 했다. 동기는 경쟁이 아니라 "사랑을 전하고 싶다" (https://dime.jp/genre/1914339/).
- **피할 것**: 돈 순위·금액 공개·많이 낸 사람 배지. SOOP 엑셀방송(별풍선 금액 경쟁)은 2025-03 세무조사와 '사이버 룸살롱' 비판, 치지직은 2025-09 과도한 후원 경쟁을 부적합 콘텐츠로 정했다. KGMA 2024 유료 투표 반발, 소비자원 2026-05 투표 앱 환불 다크패턴 지적. "공식·영구" 표현(별 이름 짓기 사례).

## 4. 제안 (상·중·하)

### 상 — 이것 없이는 아무것도 안 팔린다

1. **증거를 자랑할 만하게** (S~M)
   - R2 버킷을 연결해 받는 사람이 2D가 아니라 3D 영상을 보게 한다. 주인이 Cloudflare에서 버킷을 만드는 한 단계다(설계 문서가 '2차 전'으로 미뤄 둔 결정).
   - 녹화 때 화면 크기와 상관없이 1080×1920, 배율 1로 고정해 그린다. 단체 사진(`cerPicture`)이 이미 이 방식이다.
   - 녹화하는 선물 전광판만 1024×576 글자 그림으로 그린다.
   - 음악을 넣는다(`bgm.js`가 있다. M).
   - 무료는 워터마크 유지, 유료는 없앤다.
   - 서버 렌더는 Worker에 WebGL이 없어 바깥 렌더러가 필요하다(L). 지금은 하지 않는다.
2. **"그 분"을 판다: 메인 타워 축하 1분** (M, 주인 결정 필요)
   - 생일·기념일의 정확한 1분(예: 0시 정각, 저녁 8시 정각)을 메인 타워에 건다. **정가·선착순·하루 정원**. 입찰이 없고 포인트와 상관없어 게임이 아니다.
   - 주인이 바란 "메인 전광판에 내 것"을 경쟁 없이 주는 유일한 길이다.
   - 걸림돌: 지금 약관은 "명당(메인 타워와 큰 화면)은 돈으로 팔지 않습니다"라고 적고 있다. 팀 시간(밤 9시 팀 21:00~22:00, 목표 달성 1시간, 기념일 정시 1분)은 그대로 두고, **팀과 겹치지 않는 '개인 축하 시간'만 정가로 파는 것**으로 약관과 `docs/prime-screens.md`를 고쳐야 한다. 팬 팀이 아이돌 생일에 돈으로 메인을 사 가는 것을 막을지(개인 축하만, 계정당 상한)도 정해야 한다.
   - 가격 기준: 네이트 1시간 3만원(10명이 나눔), 야구장 50~160달러. 조사 작업자 제안 9,900~19,900원. 무료 시즌에는 가격표에만 올려 관심 수를 잰다.
3. **켜지는 순간을 모두에게** (S~M)
   - 선물이 켜질 때 광장 속보 한 줄("○○의 생일 전광판이 켜졌어요")을 띄운다. 금액은 절대 쓰지 않는다.
   - 받는 사람 페이지에 카운트다운을 두고, 정각에 친구들이 같은 순간을 보게 한다(유튜브 프리미어처럼).
   - 어제의 소원왕과 메인 타워에 걸릴 팀원에게 미리 알린다(이미 있는 순간인데 본인이 모른다).

### 중 — 상을 한 뒤 붙이면 매출이 는다

4. **광장 네컷**: 그 자리에 온 친구들 아바타가 손 흔들기·춤으로 포즈를 잡은 4컷 고화질 사진. 자체 프레임만(아이돌 사진·로고 금지). 1인 1,900~2,900원(4컷 사진 4,000~7,000원 기준). 단체 사진 코드가 바탕이 된다.
5. **함께 올리기**: 친구가 각자 2,000원짜리 "이름 한 줄"을 사고, 세 명이 모이면 보드가 커진다. 결제 하나하나가 그 자리에서 끝나야 한다(돈을 모아 두지 않는다). 이름은 금액이 아니라 시간순. 미성년자 결제 취소와 건당 수수료가 위험.
6. **받는 순간에도 파는 자리**: 받는 사람·방문자에게도 "영상 저장(고화질)", "답례 카드(친구 이름이 흐르는 영상)"를 보인다. 지금은 만든 사람만 가격표를 본다.
7. **팀이 메인에 걸린 장면**: 팀원에게 알림과 그 장면의 사진·영상. 전략 보고서의 '팀 달성 기념 영상'(2,900원)이 이것이다.
8. **가격표 바로잡기**: "큰 화면에 24시간"은 지킬 수 없다. 2번을 하면 "메인 타워 축하 1분"으로, 안 하면 실제로 열 화면으로 고친다. 3단의 9시 퍼레이드도 같은 이유로 손본다.

### 하 — 나중에

9. 아티스트·소속사에 그달의 보드를 모아 전달하는 제휴(B2B, 고르지 않고 전부 보낸다).
10. 기업 후원 '소원의 벽'(수능·연말). 모객용. 타임스퀘어 새해 소원의 벽이 같은 구조다.
11. "내가 걸렸던 기록" 보관함. 지금은 7~8일 뒤 지워진다. 처리방침의 보유 기간을 바꿔야 한다.

### 하지 않는 것

돈 순위, 금액 공개, 많이 낸 사람 배지, 유료 투표, 추첨·확률, "공식"·"영구" 같은 말.

## 5. 재는 법 (무료 시즌, 결제 없이)

이미 있는 집계로 읽는다: 선물 쪽 `start`·`made`·`made_again`, `hit`, `view`·`return_day`, `heart`, `reshare`, `save`, 가격표의 `ladder`·`pick:1-3`·`notify:1-3`(`giftsrv.js`). 새 상품(메인 타워 축하 1분, 네컷)을 가격표의 한 줄로 더해 `notify`가 얼마나 눌리는지 2주 본다. 화질을 올린 뒤 `save`와 `reshare`가 느는지 본다.

## 6. 주인이 할 것 (순서대로)

1. **오늘 정하기: 메인 타워 '개인 축하 1분'을 정가로 팔 수 있게 할지.** 예라면 약관과 명당 규칙을 고치고 팀 시간과 겹치지 않게 나눈다. 아니면 4장 2번을 빼고 나머지로 간다.
2. R2 버킷 만들기에 동의하기(Cloudflare 대시보드에서 버킷 하나, 무료 10GB 안). 받는 사람이 3D 영상을 보는 데 필요한 유일한 바깥 단계다.
3. 그다음 본 세션이 Opus 작업자로 상 1·3번(화질, 켜지는 순간)을 만들고 로컬에서 보여 드린다. 결제는 만들지 않는다.
4. 오늘 고친 약관·질의서(소원 순위 상금·스폰서 코드 없앰)를 배포하고, 게임위 확인 요청을 낸다. 비게임으로 가기로 했으니 지금 내도 된다. 1번이 예라면 질의서의 '판매할 디지털 상품'에 메인 타워 축하 1분을 더한다.
