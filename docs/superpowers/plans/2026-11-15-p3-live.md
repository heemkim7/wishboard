# Phase 3 Live Operations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 매일 21시 10분 볼 드랍을 서버 시계에 맞추고, 관리자 달력으로 주제를 바꾸며, 2027년 1월 새해 시즌 한 행만 시드한다.

**Architecture:** 메인 타워가 창 밖에서 거절되는 규칙은 `p1-economy`의 `auction_closed`가 이미 한다. 이 계획은 Room 알람이 `{t:'BALL', open, until}`을 방송하고, 크론이 20:50 예고와 21:00 주간 마감을 맡는다. `ui.js`는 열지 않는다. 볼 연출만 `timesSquare3d.js`에 붙이고 `{t:'BALL'}` 처리 함수는 `live.js` `applyBall`이다.

**Tech Stack:** `worker.js`, `wrangler.jsonc`, `admin.html`, `live.js`, `timesSquare3d.js`.

## Global Constraints

- Meter DO 일일 예산 가드는 80% lean, 95% hard를 유지한다. `PLAN=paid`를 넣지 않는다. Workers 계정은 운영자가 올리기 전까지 Free다. `env.PLAN === 'paid'`는 유료 전용 작업을 건너뛰는 런타임 검사로만 쓴다.
- Room DO WebSocket hibernation을 유지한다. 핑, 스태일, 알람 주기와, 사람이 없을 때 알람 해제를 지우지 않는다.
- 위치 패킷은 `v2: {t:'P', k, a:[x,y,...]}`다. 서버가 받는 기존 메시지는 `t:'p'`이고, 릴레이는 `t:'P'`다. 이 둘을 한 글자로 합치지 않는다. 같은 층, `NEAR_R` 1600 안을 우선하고 먼 피어는 `FAR_MS`로 줄인다. `net.js` 데드레커닝 1.15초를 유지한다.
- `/rt/guest`는 HMAC(`GUEST_KEY`)이다. Supabase 익명 가입으로 바꾸지 않는다.
- 내 캐릭터 위치는 로컬 입력만 쓴다. 서버 좌표로 내 플레이어를 덮어쓰지 않는다. 좌표 변환은 `toNetUnits` / `fromNetUnits`만 쓴다. `floor = 0`.
- 자유 텍스트 채팅은 없다. 리액션은 `{t:'E', k, e: 1~4}`다.
- 브라우저에는 publishable 키만 둔다. `service_role`을 코드에 넣지 않는다. `.dev.vars`를 읽거나 커밋하지 않는다. 시크릿 값을 채팅, 코드, 커밋 메시지에 적지 않는다.
- 지도는 OSM만 쓴다. `ts3d/nycmeta.js`를 손으로 고치지 않는다.
- `schema.sql`은 통째로 다시 실행한다. 변경은 멱등이다. `CREATE TABLE IF NOT EXISTS`, `ADD COLUMN IF NOT EXISTS`, `CREATE OR REPLACE FUNCTION`, `DROP POLICY IF EXISTS`, `CREATE INDEX IF NOT EXISTS`, `INSERT ... ON CONFLICT DO NOTHING`. `DROP TABLE`은 없다. 시그니처가 바뀌는 함수만 `DROP FUNCTION IF EXISTS`로 그 시그니처를 지운 뒤 만든다.
- 캐시: 이번 태스크에서 바뀐 모듈의 import `?v=`와 `index.html`의 `main.js?v=`를 같은 토큰으로 함께 올린다.
- 태스크 안에서 `npx wrangler deploy`, Supabase SQL 실행, `.dev.vars` 읽기, `git push`를 하지 않는다.
- 테스트는 `node`로 직접 실행한다. `package.json`을 만들지 않는다. `test/cf-stub.mjs`와 `test/plaza.test.mjs` 방식을 따른다. `https://studio.wishboard.workers.dev`를 호출하지 않는다. 테스트는 프로덕션 Supabase에 점령·지급을 쓰지 않는다. 로컬 `wrangler dev`도 프로덕션 DB를 본다.
- 이름표 색은 재질 이름이 `Main`인 메시에만 칠한다.
- 원점은 7번가 × W 45th St. 북쪽은 −Z, 동쪽은 +X. 채널은 `chapel:square`부터 `chapel:square-8`. `CAP`은 50이다.

- [ ] **Step 3: Write minimal implementation**

```js
export function nextBallUntil(now, open) {
  const kst = new Date(now + 9 * 3600000);
  const y = kst.getUTCFullYear(), m = kst.getUTCMonth(), d = kst.getUTCDate();
  const hour = open ? 21 : 21;
  const minute = open ? 10 : 0;
  let stamp = Date.UTC(y, m, d, hour - 9, minute, 0);
  if (!open && stamp <= now) stamp = Date.UTC(y, m, d + 1, hour - 9, minute, 0);
  return stamp;
}

export function applyBall(msg) {
  if (!msg || msg.t !== 'BALL') return '';
  return msg.open ? '21:10까지 메인 타워가 열려 있어요' : '다음 볼은 21:00이에요';
}

export function applyOps(ops) {
  if (!ops || !ops.copy) return '';
  return String(ops.copy).slice(0, 80);
}
```

Room 알람이 KST 날짜의 `ballOpen` 경계를 넘기면 `this.bc({ t:'BALL', open, until: nextBallUntil(Date.now(), open) })`를 한 번 보낸다. 입장 `ok`에도 같은 객체를 넣는다. 방당 하루 열림·닫힘 각 1회를 넘기지 않도록 `ag` 키 `ball`에 날짜와 상태를 둔다. 알람 주기(연결 중 60초, 빈 방 해제)는 유지한다.

`timesSquare3d.js`는 `applyBall`을 호출하지 않는다. `main.js`는 `ui.setNextLine(applyBall(msg))`를 호출하고, `msg.open`일 때만 기존 광장 열기 연출 함수를 한 번 호출한다. `ops`가 있으면 `ui.setNextLine(applyOps(ops))`를 호출한다. 그 연출 함수의 코인 2배 클라 타이머는 호출하지 않는다. 2배는 서버 `ballOpen`만 한다.

`GET /rt/here`의 `live`가 40 미만이면 `main.js`가 채널 칩을 숨긴다. 40 이상이면 지금처럼 보인다. 채널 이동 로직은 바꾸지 않는다.

`readWorld`는 KST 오늘과 겹치는 `ops_events` 한 줄을 `ops: { id, theme, title, copy }`로 넣는다. 없으면 필드를 생략한다. `main.js`는 `ops`가 있으면 `applyOps`를 호출한다.

`wrangler.jsonc`의 `triggers.crons`에 두 문자열을 추가한다. `5 * * * *`는 지우지 않는다.

```jsonc
"triggers": { "crons": ["5 * * * *", "50 11 * * *", "0 12 * * *"] }
```

`scheduled`는 기존처럼 `env.PLAN !== 'paid'`이면 즉시 return 한다. paid일 때 `50 11 * * *`(KST 20:50)은 수신함 `kind:'ball'`만 넣고 푸시 템플릿은 `p1-return`의 `ball` 문장이다. `0 12 * * *`(KST 21:00)은 일요일(KST)일 때만 그 주 `tribe_scores` 1위의 `roof_until = now() + interval '7 days'`를 쓴다. 동점이면 `tribe_id` 사전순이다. 1위가 없으면 지붕 이름을 비운다. 점수 행은 삭제하지 않는다. 일요일 판정은 `(timezone('Asia/Seoul', now()))`의 `dow`가 0일 때다.
