# Phase 1 Share Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 전광판마다 카드 주소와 미리보기 이미지를 두고, 선물 링크는 받는 사람을 그 칸 앞에 세우며, 5초 세로 클립은 기기에만 저장한다.

**Architecture:** HTML은 `GET /rt/card/:slot`이 만든다. PNG는 `cardpng.js` `renderCardPng`가 그리고 Meter `cards`에 둔다. `env.PLAN !== 'paid'`이면 PNG를 그리지 않고 `og:image`는 `/og.jpg`다. 클립은 서버에 올리지 않는다.

**Tech Stack:** `share.js`, `cardpng.js`, `worker.js`, `ui.js`, `plaza-account.js`, Workers `CompressionStream`.

## Global Constraints

- Meter DO 일일 예산 가드는 80% lean, 95% hard를 유지한다. `PLAN=paid`를 넣지 않는다. Workers 계정은 운영자가 올리기 전까지 Free다. `env.PLAN === 'paid'`는 유료 전용 작업을 건너뛰는 런타임 검사로만 쓴다.
- Room DO WebSocket hibernation을 유지한다. 핑, 스태일, 알람 주기와, 사람이 없을 때 알람 해제를 지우지 않는다.
- 위치 패킷은 `v2: {t:'P', k, a:[x,y,...]}`다. 서버가 받는 기존 메시지는 `t:'p'`이고, 릴레이는 `t:'P'`다. 이 둘을 한 글자로 합치지 않는다. 같은 층, `NEAR_R` 1600 안을 우선하고 먼 피어는 `FAR_MS`로 줄인다. `net.js` 데드레커닝 1.15초를 유지한다.
- `/rt/guest`는 HMAC(`GUEST_KEY`)이다. Supabase 익명 가입으로 바꾸지 않는다.
- 내 캐릭터 위치는 로컬 입력만 쓴다. 서버 좌표로 내 플레이어를 덮어쓰지 않는다. 좌표 변환은 `toNetUnits` / `fromNetUnits`만 쓴다. `floor = 0`.
- 자유 텍스트 채팅은 없다. 리액션은 `{t:'E', k, e: 1~4}`다.
- 브라우저에는 publishable 키만 둔다. `service_role`을 코드에 넣지 않는다. `.dev.vars`를 읽거나 커밋하지 않는다. 시크릿 값을 채팅, 코드, 커밋 메시지에 적지 않는다.
- 지도는 OSM만 쓴다. `ts3d/nycmeta.js`를 손으로 고치지 않는다.
- `schema.sql`은 통째로 다시 실행한다. 변경은 멱등이다. `CREATE TABLE IF NOT EXISTS`, `ADD COLUMN IF NOT EXISTS`, `CREATE OR REPLACE FUNCTION`, `DROP POLICY IF EXISTS`, `CREATE INDEX IF NOT EXISTS`, `INSERT ... ON CONFLICT DO NOTHING`. `DROP TABLE`은 없다. 시그니처가 바뀌는 함수만 `DROP FUNCTION IF EXISTS`로 그 시그니처를 지운 뒤 만든다.
- 캐시: 이번 태스크에서 바뀐 모듈의 import `?v=`와 `index.html`의 `main.js?v=`를 같은 토큰으로 함께 올린다.
- 태스크 안에서 `npx wrangler deploy`, Supabase SQL 실행, `.dev.vars` 읽기, `git push`를 하지 않는다.
- 테스트는 `node`로 직접 실행한다. `package.json`을 만들지 않는다. `test/cf-stub.mjs`와 `test/plaza.test.mjs` 방식을 따른다. `https://studio.wishboard.workers.dev`를 호출하지 않는다. 테스트는 프로덕션 Supabase에 점령·지급을 쓰지 않는다. 로컬 `wrangler dev`도 프로덕션 DB를 본다.
- 이름표 색은 재질 이름이 `Main`인 메시에만 칠한다.
- 원점은 7번가 × W 45th St. 북쪽은 −Z, 동쪽은 +X. 채널은 `chapel:square`부터 `chapel:square-8`. `CAP`은 50이다.

- [ ] **Step 3: Write minimal implementation**

`cardpng.js`는 `CompressionStream('deflate')`로 zlib 래퍼를 만들고 PNG IHDR+IDAT+IEND를 조립한다. 픽셀은 600×315 RGB다. tier `S`는 위 막대 `#f5c16c`, 그 외는 `#7ee0ff`. `name` `line1` `line2` `line3`의 코드 포인트를 8×8 블록으로 왼쪽 위에 찍는다. 한글 폰트 파일은 넣지 않는다. 블록이 달라지면 테스트의 `notDeepEqual`이 통과한다.

```js
const CRC_TABLE = new Uint32Array(256);
for (let n = 0; n < 256; n++) {
  let c = n;
  for (let k = 0; k < 8; k++) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;
  CRC_TABLE[n] = c;
}
function crc(buf) {
  let c = 0xffffffff;
  for (const b of buf) c = CRC_TABLE[(c ^ b) & 0xff] ^ (c >>> 8);
  return (c ^ 0xffffffff) >>> 0;
}
function chunk(type, data) {
  const body = new Uint8Array(4 + data.length);
  body.set(new TextEncoder().encode(type), 0);
  body.set(data, 4);
  const out = new Uint8Array(12 + data.length);
  const view = new DataView(out.buffer);
  view.setUint32(0, data.length);
  out.set(body, 4);
  view.setUint32(8 + data.length, crc(body));
  return out;
}
export async function renderCardPng(card) {
  const w = 600, h = 315;
  const raw = new Uint8Array((w * 3 + 1) * h);
  const gold = card?.tier === 'S';
  for (let y = 0; y < h; y++) {
    const o = y * (w * 3 + 1);
    raw[o] = 0;
    for (let x = 0; x < w; x++) {
      const i = o + 1 + x * 3;
      const bar = y < 28;
      raw[i] = bar ? (gold ? 245 : 126) : 18;
      raw[i + 1] = bar ? (gold ? 193 : 224) : 24;
      raw[i + 2] = bar ? (gold ? 108 : 255) : 44;
    }
  }
  const text = [card?.name, card?.line1, card?.line2, card?.line3].map((s) => String(s || '')).join('\n');
  let i = 0;
  for (const ch of text) {
    const code = ch.codePointAt(0);
    const gx = 16 + (i % 24) * 10;
    const gy = 48 + Math.floor(i / 24) * 10;
    for (let dy = 0; dy < 8; dy++) for (let dx = 0; dx < 8; dx++) {
      if (((code >> ((dx + dy) % 15)) & 1) === 0) continue;
      const x = gx + dx, y = gy + dy;
      if (x >= w || y >= h) continue;
      const p = y * (w * 3 + 1) + 1 + x * 3;
      raw[p] = 255; raw[p + 1] = 255; raw[p + 2] = 255;
    }
    i += 1;
  }
  const stream = new Blob([raw]).stream().pipeThrough(new CompressionStream('deflate'));
  const z = new Uint8Array(await new Response(stream).arrayBuffer());
  const ihdr = new Uint8Array(13);
  const iv = new DataView(ihdr.buffer);
  iv.setUint32(0, w); iv.setUint32(4, h); ihdr[8] = 8; ihdr[9] = 2;
  const sig = new Uint8Array([137, 80, 78, 71, 13, 10, 26, 10]);
  const parts = [sig, chunk('IHDR', ihdr), chunk('IDAT', z), chunk('IEND', new Uint8Array())];
  const len = parts.reduce((n, p) => n + p.length, 0);
  const png = new Uint8Array(len);
  let at = 0;
  for (const p of parts) { png.set(p, at); at += p.length; }
  if (png.length > 40000) throw new Error('card png over 40KB');
  return png;
}
```

`schema.sql`:

```sql
ALTER TABLE public.wallets ADD COLUMN IF NOT EXISTS ref_code TEXT;
CREATE UNIQUE INDEX IF NOT EXISTS wallets_ref_code_idx ON public.wallets (ref_code) WHERE ref_code IS NOT NULL;

CREATE OR REPLACE FUNCTION public.ensure_ref_code(p_key TEXT, p_actor_id TEXT)
RETURNS TEXT
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public
AS $$
DECLARE
  v_secret TEXT;
  v_code TEXT;
  v_n INT := 0;
BEGIN
  SELECT key_value INTO v_secret FROM public.app_secrets WHERE key_name = 'FLUSH_KEY';
  IF v_secret IS NULL OR p_key IS DISTINCT FROM v_secret THEN
    RAISE EXCEPTION 'Unauthorized worker key';
  END IF;
  SELECT ref_code INTO v_code FROM public.wallets WHERE actor_id = p_actor_id;
  IF v_code IS NOT NULL THEN
    RETURN v_code;
  END IF;
  LOOP
    v_n := v_n + 1;
    v_code := substr(md5(p_actor_id || clock_timestamp()::text || v_n::text), 1, 8);
    BEGIN
      UPDATE public.wallets SET ref_code = v_code WHERE actor_id = p_actor_id AND ref_code IS NULL;
      EXIT;
    EXCEPTION WHEN unique_violation THEN
      IF v_n > 8 THEN RAISE; END IF;
    END;
  END LOOP;
  RETURN v_code;
END;
$$;
```

- [ ] **Step 3: Write minimal implementation**

```js
import { SLOT_IDS } from './balance.js';
import { SITE } from './plaza-account.js';

export function cardUrl(slot, opts = {}) {
  if (!SLOT_IDS.includes(String(slot || ''))) return '';
  const u = new URL('rt/card/' + slot, SITE);
  if (opts.gift) u.searchParams.set('gift', '1');
  if (opts.ref && /^[a-z0-9]{8}$/.test(opts.ref)) u.searchParams.set('ref', opts.ref);
  return u.toString();
}

export async function copyCard(slot) {
  const url = cardUrl(slot);
  if (!url || !navigator.clipboard) return false;
  await navigator.clipboard.writeText(url);
  return true;
}

export async function saveClip(canvas) {
  if (typeof MediaRecorder === 'undefined' || !canvas?.captureStream) return null;
  const stream = canvas.captureStream(30);
  const rec = new MediaRecorder(stream, { mimeType: MediaRecorder.isTypeSupported('video/webm') ? 'video/webm' : '' });
  const chunks = [];
  rec.ondataavailable = (ev) => { if (ev.data?.size) chunks.push(ev.data); };
  const done = new Promise((resolve) => { rec.onstop = () => resolve(new Blob(chunks, { type: rec.mimeType || 'video/webm' })); });
  rec.start();
  await new Promise((r) => setTimeout(r, 5000));
  rec.stop();
  const blob = await done;
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = 'wishboard.webm';
  a.click();
  return blob;
}
```

`MediaRecorder`가 없으면 `saveClip`은 null을 반환하고 호출부가 기존 `capture()` JPEG를 저장한다. 서버 업로드는 없다.

`main.js`는 `?focus=` 입장 때 `focus_enter`를 `{ slot, ref }`로 보낸다. `ref`는 쿼리 문자열이고 계정 id가 아니다. 공유 버튼은 `copyCard` 성공 뒤 `share_send`를 보낸다. 버튼은 `setQuietBlock`이 false가 된 다음에만 연다. `gift=1`은 기존 폭죽을 유지하고, 카드 URL의 목적지가 `/?focus=&gift=1`이 되게 `cardUrl`만 쓴다. 하드코드된 `studio.wishboard.workers.dev/?focus=` 복사 문구는 `cardUrl`로 바꾼다.
