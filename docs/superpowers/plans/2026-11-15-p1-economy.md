# Phase 1 Economy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 반복 수입을 서버 표와 시간당 상한으로 옮기고, 빼앗김은 구매자가 낸 코인 안에서만 80% 환불과 지주 몫을 나눈다.

**Architecture:** 숫자는 `balance.js`의 `PAY`, `scaledPay`, `farePay`, `claimSplit`만 본다. Room은 그 함수로 `{t:'PAY'}`를 보내고, 지갑 이동은 `claim_billboard` 14인자 한 트랜잭션이다. 피버는 반복 지급에만 한 번 곱한다. `attend` `mission` `quest` `hello`에는 곱하지 않는다. 설계 2장이 지금 트리에서 피버가 출석 상한을 60으로 만든다고 적은 것은 현재 동작이고, 설계 8장이 이 계획의 규칙이다.

**Tech Stack:** `balance.js`, `worker.js` Room DO, `schema.sql`, `main.js`, `node --test`와 `test/plaza.test.mjs`의 `makeRoom` / `openSock`.

## Global Constraints

- Meter DO 일일 예산 가드는 80% lean, 95% hard를 유지한다. `PLAN=paid`를 넣지 않는다. Workers 계정은 운영자가 올리기 전까지 Free다. `env.PLAN === 'paid'`는 유료 전용 작업을 건너뛰는 런타임 검사로만 쓴다.
- Room DO WebSocket hibernation을 유지한다. 핑, 스태일, 알람 주기와, 사람이 없을 때 알람 해제를 지우지 않는다.
- 위치 패킷은 `v2: {t:'P', k, a:[x,y,...]}`다. 서버가 받는 기존 메시지는 `t:'p'`이고, 릴레이는 `t:'P'`다. 이 둘을 한 글자로 합치지 않는다. 같은 층, `NEAR_R` 1600 안을 우선하고 먼 피어는 `FAR_MS`로 줄인다. `net.js` 데드레커닝 1.15초를 유지한다.
- `/rt/guest`는 HMAC(`GUEST_KEY`)이다. Supabase 익명 가입으로 바꾸지 않는다.
- 내 캐릭터 위치는 로컬 입력만 쓴다. 서버 좌표로 내 플레이어를 덮어쓰지 않는다. 좌표 변환은 `toNetUnits` / `fromNetUnits`만 쓴다. `floor = 0`.
- 자유 텍스트 채팅은 없다. 리액션은 `{t:'E', k, e: 1~4}`다.
- 브라우저에는 publishable 키만 둔다. `service_role`을 코드에 넣지 않는다. `.dev.vars`를 읽거나 커밋하지 않는다. 시크릿 값을 채팅, 코드, 커밋 메시지에 적지 않는다.
- 지도는 OSM만 쓴다. `ts3d/nycmeta.js`를 손으로 고치지 않는다.
- `schema.sql`은 통째로 다시 실행한다. 변경은 멱등이다. `CREATE TABLE IF NOT EXISTS`, `ADD COLUMN IF NOT EXISTS`, `CREATE OR REPLACE FUNCTION`, `DROP POLICY IF EXISTS`, `CREATE INDEX IF NOT EXISTS`, `INSERT ... ON CONFLICT DO NOTHING`. `DROP TABLE`은 없다. 시그니처가 바뀌는 함수만 `DROP FUNCTION IF EXISTS`로 그 시그니처를 지운 뒤 만든다.
- 캐시: 이번 태스크에서 바뀐 모듈의 import `?v=`와 `index.html`의 `main.js?v=`를 같은 토큰으로 함께 올린다.
- 태스크 안에서 `npx wrangler deploy`, Supabase SQL 실행, `.dev.vars` 읽기, `git push`를 하지 않는다.
- 테스트는 `node`로 직접 실행한다. `package.json`을 만들지 않는다. `test/cf-stub.mjs`와 `test/plaza.test.mjs` 방식을 따른다. `https://studio.wishboard.workers.dev`를 호출하지 않는다. 테스트는 프로덕션 Supabase에 점령·지급을 쓰지 않는다. 로컬 `wrangler dev`도 프로덕션 DB를 본다.
- 이름표 색은 재질 이름이 `Main`인 메시에만 칠한다.
- 원점은 7번가 × W 45th St. 북쪽은 −Z, 동쪽은 +X. 채널은 `chapel:square`부터 `chapel:square-8`. `CAP`은 50이다.

```js
  bake: { miss: 0, good: 6, gold: 16, minS: 8, maxS: 40, perHour: 40, nearM: 12 },
  dance: { minS: 25, maxS: 40, perHour: 6, nearM: 8 },
```

```js
  pouch: { base: 20, cap: 30, gapMs: 25000, perHour: 4, perDay: 8 },
  fare: { base: 20, gapMs: 40000, perHour: 15, pickGapMs: 20000, pickMoveM: 15, pickMax: 4 },
  lottery: { hit: 25, sides: 15 },
  attend: 30,
  mission: 15,
  hello: 40,
  quest: { fare: 50, cheer: 30, stunt: 40, all: 100 },
  hourCap: 1200,
  ballHourCap: 1600,
  playFullS: 3600,
  stall: { x: 21, z: 118 },
  stage: { x: 0, z: 366 },
});

export function curveOf(playSeconds) {
  return Number(playSeconds) < PAY.playFullS ? 1 : 0.3;
}
export function ballOpen(now = Date.now()) {
  const parts = new Intl.DateTimeFormat('en-GB', { timeZone: 'Asia/Seoul', hour: '2-digit', minute: '2-digit', second: '2-digit', hourCycle: 'h23' }).formatToParts(new Date(now));
  const g = (t) => Number(parts.find((p) => p.type === t).value);
  const sec = g('hour') * 3600 + g('minute') * 60 + g('second');
  return sec >= 21 * 3600 && sec < 21 * 3600 + 600;
}
export function auctionClosed(slotId, now = Date.now()) {
  return String(slotId || '').startsWith('MAIN_') && !ballOpen(now);
}
export function feverBall(fever, ball) {
  return Math.min(2, (fever ? 2 : 1) * (ball ? 2 : 1));
}
export function scaledPay(base, state = {}) {
  const scaled = Math.floor(Number(base) * curveOf(state.playSeconds || 0) * feverBall(!!state.fever, !!state.ball));
  const cap = state.ball ? PAY.ballHourCap : PAY.hourCap;
  return Math.max(0, Math.min(scaled, cap - (Number(state.earnedInWindow) || 0)));
}
export function claimSplit({ mode = 'claim', bid = 0, prevBid = 0, plot = false, landlordId = '', buyerId = '', prevId = '', live = false } = {}) {
  const B = Math.max(0, Math.floor(Number(bid) || 0));
  const prev = Math.max(0, Math.floor(Number(prevBid) || 0));
  if (mode === 'starter') return { charge: 0, refund: 0, landlord: 0, burn: 0 };
  if (mode === 'edit') {
    const delta = Math.max(0, B - prev);
    const landlord = plot && landlordId && landlordId !== buyerId ? Math.floor(delta / 2) : 0;
    return { charge: delta, refund: 0, landlord, burn: delta - landlord };
  }
  if (!live) {
    const landlord = plot && landlordId && landlordId !== buyerId ? Math.floor(B / 2) : 0;
    return { charge: B, refund: 0, landlord, burn: B - landlord };
  }
  const refund = Math.min(B, Math.floor(prev * 80 / 100));
  let landlord = Math.floor((B - refund) / 2);
  if (!(plot && landlordId && landlordId !== buyerId && landlordId !== prevId)) landlord = 0;
  return { charge: B, refund, landlord, burn: B - refund - landlord };
}
export function fareRaw(riders, revenge, fever, ball) {
  const table = [1, 2.2, 3.8, 6, 10];
  const n = Math.min(5, Math.max(1, Math.floor(Number(riders)) || 1));
  return Math.round(PAY.fare.base * table[n - 1] * (revenge ? 2 : 1) * feverBall(!!fever, !!ball));
}
export function farePay(riders, state = {}) {
  const curved = Math.floor(fareRaw(riders, state.revenge, state.fever, state.ball) * curveOf(state.playSeconds || 0));
  const cap = state.ball ? PAY.ballHourCap : PAY.hourCap;
  return Math.max(0, Math.min(curved, cap - (Number(state.earnedInWindow) || 0)));
}
export function bakeBase(result) {
  if (result === 'gold') return PAY.bake.gold;
  if (result === 'good') return PAY.bake.good;
  return 0;
}
export function danceBase(score) {
  const n = Math.max(0, Math.min(100, Math.floor(Number(score) || 0)));
  if (n >= 90) return 12;
  if (n >= 75) return 8;
  if (n >= 55) return 4;
  return 2;
}
```

```js
  payState(a) {
    const q = this.ctx.storage.sql, now = Date.now(), day = kstDay(now);
    let start = agGet(q, a.k, 'eht', ''), sum = agGet(q, a.k, 'ehs', '');
    if (!start || now / 1000 - start >= 3600) { start = Math.floor(now / 1000); sum = 0; agPut(q, a.k, 'eht', '', start); agPut(q, a.k, 'ehs', '', 0); }
    return { playSeconds: agGet(q, a.k, 'play', day), earnedInWindow: sum, fever: this.feverScale(a.k) > 1, ball: ballOpen(now), windowStart: start };
  }
  notePlay(a, add, amount) {
    const q = this.ctx.storage.sql, day = kstDay();
    agPut(q, a.k, 'play', day, agGet(q, a.k, 'play', day) + add);
    agPut(q, a.k, 'ehs', '', agGet(q, a.k, 'ehs', '') + amount);
  }
  grantFinal(a, amount, nick, kind) {
    if (amount < 1) return 0;
    const now = Date.now(), name = clip(nick, 16), q = this.ctx.storage.sql;
    if (!this.tapN) this.tapAt = now;
    q.exec('insert into coin(uid, nick, delta, n, at) values(?, ?, ?, 1, ?) on conflict(uid) do update set delta = delta + excluded.delta, n = n + excluded.n, nick = excluded.nick, at = min(coin.at, excluded.at)', a.k, name, amount, now);
    this.tapN++;
    if (this.tapN >= FLUSH_N) this.flush(); else this.arm();
    return amount;
  }
  repeatPay(a, base, nick, kind, playAdd, perHour) {
    if (!a?.k || this.lvl >= 2) return 0;
    this.tapDb();
    const q = this.ctx.storage.sql, now = Date.now(), bucket = String(Math.floor(now / 3600000));
    const used = agGet(q, a.k, 'hr:' + kind, bucket);
    if (perHour && used >= perHour) return 0;
    const state = this.payState(a);
    const amount = scaledPay(base, state);
    if (amount < 1) return 0;
    agPut(q, a.k, 'hr:' + kind, bucket, used + 1);
    this.notePlay(a, playAdd, amount);
    return this.grantFinal(a, amount, nick, kind);
  }
```
