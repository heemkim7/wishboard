**Goal:** 입장 뒤 포차로 안내하고, 첫 전광판은 무료 네 칸 중 하나를 3단계로 걸며, 축하 5초 동안 계정 창과 알림 동의가 끼어들지 않는다.

**Architecture:** `ftue.js`가 웨이포인트와 마법사와 잠금을 맡고, `ui.js`는 `openClaimStep` `setNextLine` `setQuietBlock`만 추가한다. 환영은 칸을 덮지 않고 Room의 `{t:'WELCOME', name}`을 `setTicker`로 8초 보여 준다. 그 송신은 `p1-economy`가 `tr` 분기에 넣었다.

**Tech Stack:** `ftue.js`, `ui.js`, `main.js`, `timesSquare3d.js`, `balance.js`, `index.html`.

## Global Constraints

- Meter DO 일일 예산 가드는 80% lean, 95% hard를 유지한다. `PLAN=paid`를 넣지 않는다. Workers 계정은 운영자가 올리기 전까지 Free다. `env.PLAN === 'paid'`는 유료 전용 작업을 건너뛰는 런타임 검사로만 쓴다.
- Room DO WebSocket hibernation을 유지한다. 핑, 스태일, 알람 주기와, 사람이 없을 때 알람 해제를 지우지 않는다.
- 위치 패킷은 `v2: {t:'P', k, a:[x,y,...]}`다. 서버가 받는 기존 메시지는 `t:'p'`이고, 릴레이는 `t:'P'`다. 이 둘을 한 글자로 합치지 않는다. 같은 층, `NEAR_R` 1600 안을 우선하고 먼 피어는 `FAR_MS`로 줄인다. `net.js` 데드레커닝 1.15초를 유지한다.
- `/rt/guest`는 HMAC(`GUEST_KEY`)이다. Supabase 익명 가입으로 바꾸지 않는다.
- 내 캐릭터 위치는 로컬 입력만 쓴다. 서버 좌표로 내 플레이어를 덮어쓰지 않는다. 좌표 변환은 `toNetUnits` / `fromNetUnits`만 쓴다. `floor = 0`.
- 자유 텍스트 채팅은 없다. 리액션은 `{t:'E', k, e: 1~4}`다.
- 브라우저에는 publishable 키만 둔다. `service_role`을 코드에 넣지 않는다. `.dev.vars`를 읽거나 커밋하지 않는다. 시크릿 값을 채팅, 코드, 커밋 메시지에 적지 않는다.
- 지도는 OSM만 쓴다. `ts3d/nycmeta.js`를 손으로 고치지 않는다.
- `schema.sql`은 통째로 다시 실행한다. 변경은 멱등이다. `CREATE TABLE IF NOT EXISTS`, `ADD COLUMN IF NOT EXISTS`, `CREATE OR REPLACE FUNCTION`, `DROP POLICY IF EXISTS`, `CREATE INDEX IF NOT EXISTS`, `INSERT ... ON CONFLICT DO NOTHING`. `DROP TABLE`은 없다. 시그니처가 바뀌는 함수만 `DROP FUNCTION IF EXISTS`로 그 시그니처를 지운 뒤 만든다.
- 캐시: 이번 태스크에서 바뀐 모듈의 import `?v=`와 `index.html`의 `main.js?v=`를 같은 토큰으로 함께 올린다.
- 태스크 안에서 `npx wrangler deploy`, Supabase SQL 실행, `.dev.vars` 읽기, `git push`를 하지 않는다.
- 테스트는 `node`로 직접 실행한다. `package.json`을 만들지 않는다. `test/cf-stub.mjs`와 `test/plaza.test.mjs` 방식을 따른다. `https://studio.wishboard.workers.dev`를 호출하지 않는다. 테스트는 프로덕션 Supabase에 점령·지급을 쓰지 않는다. 로컬 `wrangler dev`도 프로덕션 DB를 본다.
- 이름표 색은 재질 이름이 `Main`인 메시에만 칠한다.
- 원점은 7번가 × W 45th St. 북쪽은 −Z, 동쪽은 +X. 채널은 `chapel:square`부터 `chapel:square-8`. `CAP`은 50이다.

```js
import { blockedText } from './plaza-account.js';

export function lockCelebration(ms) {
  const n = Math.floor(Number(ms));
  return n === 5000 ? 5000 : 0;
}

export function claimWizard(slot) {
  const freeIds = ['STREET_8', 'STREET_9', 'STREET_10', 'STREET_11'];
  const state = { step: 1, slot: String(slot || ''), lines: ['', '', ''], emoji: '✨', theme: 'cyber_navy' };
  return {
    get step() { return state.step; },
    get slot() { return state.slot; },
    get free() { return freeIds.includes(state.slot); },
    get mode() { return this.free ? 'starter' : 'claim'; },
    choose(id) { state.slot = String(id || ''); state.step = 1; },
    linesOk(a, b, c) {
      const rows = [a, b, c].map((s) => String(s || ''));
      if (rows.some((s) => [...s].length > 16)) return false;
      if (rows.some((s) => blockedText(s))) return false;
      state.lines = rows;
      return true;
    },
    next() { if (state.step < 3) state.step += 1; return state.step; },
    payload() {
      return { slot_id: state.slot, bid: this.free ? 0 : undefined, mode: this.mode, line1: state.lines[0], line2: state.lines[1], line3: state.lines[2], emoji: state.emoji, bg_theme: state.theme };
    },
  };
}

export function startFtue(ctx) {
  const { ui, world, balance } = ctx;
  ui.setNextLine?.('붕어빵 포차로 가 보세요');
  world.setWaypoint?.(balance ? { x: 21, z: 118 } : { x: 21, z: 118 });
  return { onBakePay() { world.setWaypoint?.(null); ui.setNextLine?.('메인거리 무료 칸에 이름을 걸어 보세요'); } };
}
```

`ui.js`가 반환하는 객체에 세 함수를 넣는다.

```js
  let quietBlock = false;
  function setQuietBlock(on) { quietBlock = !!on; }
  function setNextLine(text) {
    if (!nextLineEl) return;
    nextLineEl.textContent = String(text || '');
    nextLineEl.hidden = !text;
  }
  function openClaimStep(n, model) {
    openSheet('전광판 걸기', n + '/3', (host) => {
      if (n === 1) {
        const ids = [...BALANCE.starterSlots, model.slot];
        for (const id of ids) host.append(h('button', { class: 'btn', type: 'button', text: id, onclick: () => { model.choose(id); openClaimStep(1, model); } }));
        host.append(h('button', { class: 'btn gold', type: 'button', text: '다음', style: { position: 'sticky', bottom: '0' }, onclick: () => openClaimStep(2, model) }));
      } else if (n === 2) {
        const inputs = [0, 1, 2].map(() => h('input', { class: 'input', maxLength: 16 }));
        host.append(...inputs);
        host.append(h('button', { class: 'btn gold', type: 'button', text: '다음', style: { position: 'sticky', bottom: '0' }, onclick: () => {
          if (!model.linesOk(inputs[0].value, inputs[1].value, inputs[2].value)) { note('쓸 수 없는 문구예요', 'err'); return; }
          openClaimStep(3, model);
        } }));
      } else {
        host.append(h('p', { class: 'note', text: model.free ? '첫 칸은 코인이 들지 않아요' : '입찰이 필요해요' }));
        host.append(h('button', { class: 'btn gold cta', type: 'button', text: model.free ? '무료로 걸기' : '걸기', style: { position: 'sticky', bottom: '0' }, onclick: () => hooks.submitClaim?.(model.payload()) }));
      }
    });
  }
```

`createUI`의 return에 `openClaimStep`, `setNextLine`, `setQuietBlock`을 넣는다. `pumpLink`는 `quietBlock`이 true면 return한다.

모바일 세로에서 항상 보이는 HUD는 지갑, 조이스틱, 점령, 응원, 관람 다섯을 넘기지 않도록 겹치는 칩(퀘스트 카드, 다음 목표의 옛 줄, 복권 배너)은 기존 세로 미디어쿼리 안에 두고, `setNextLine` 요소만 세로에서 보이게 한다.

`main.js`는 인트로가 끝나면 `startFtue({ ui, world, net, balance: BALANCE })`를 호출한다. 첫 `{t:'PAY', kind:'bake'}`에서 `onBakePay()`를 호출하고 `creditNow`는 economy 계획의 핸들러에 이미 있다. `{t:'WELCOME', name}`은 `world.setTicker('방금 도착: ' + name)` 후 8초 뒤 `setTicker('')`.

`index.html`과 새 import `./ftue.js?v=20261116c`, 그리고 같이 바뀐 모듈의 쿼리를 `20261116c`로 올린다.
