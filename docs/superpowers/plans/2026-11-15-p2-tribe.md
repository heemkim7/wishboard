# Phase 2 Tribe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 소속을 서버에 저장하고, 멤버가 모은 코인으로 칸을 걸며, 응원 답례는 정해진 12문구만 쓴다.

**Architecture:** 소속은 계정당 하나다. 모금은 `pledge_tribe`가 멤버 지갑에서 `wallets`의 `tribe:<id>`로 옮긴다. 점령은 `claim_billboard`의 `p_mode = 'tribe'`이고 지불 계정은 `tribe:<id>`다. 주가 바뀌고 그 주 풀이 점령에 쓰이지 않으면 `refund_tribe_week`가 낸 사람에게 100% 되돌린다. 새 코인을 만들지 않는다.

**Tech Stack:** `schema.sql`, `worker.js`, `tribe.js`, `ui.js`.

## Global Constraints

- Meter DO 일일 예산 가드는 80% lean, 95% hard를 유지한다. `PLAN=paid`를 넣지 않는다. Workers 계정은 운영자가 올리기 전까지 Free다. `env.PLAN === 'paid'`는 유료 전용 작업을 건너뛰는 런타임 검사로만 쓴다.
- Room DO WebSocket hibernation을 유지한다. 핑, 스태일, 알람 주기와, 사람이 없을 때 알람 해제를 지우지 않는다.
- 위치 패킷은 `v2: {t:'P', k, a:[x,y,...]}`다. 서버가 받는 기존 메시지는 `t:'p'`이고, 릴레이는 `t:'P'`다. 이 둘을 한 글자로 합치지 않는다. 같은 층, `NEAR_R` 1600 안을 우선하고 먼 피어는 `FAR_MS`로 줄인다. `net.js` 데드레커닝 1.15초를 유지한다.
- `/rt/guest`는 HMAC(`GUEST_KEY`)이다. Supabase 익명 가입으로 바꾸지 않는다.
- 내 캐릭터 위치는 로컬 입력만 쓴다. 서버 좌표로 내 플레이어를 덮어쓰지 않는다. 좌표 변환은 `toNetUnits` / `fromNetUnits`만 쓴다. `floor = 0`.
- 자유 텍스트 채팅은 없다. 리액션은 `{t:'E', k, e: 1~4}`다.
- 브라우저에는 publishable 키만 둔다. `service_role`을 코드에 넣지 않는다. `.dev.vars`를 읽거나 커밋하지 않는다. 시크릿 값을 채팅, 코드, 커밋 메시지에 적지 않는다.
- 지도는 OSM만 쓴다. `ts3d/nycmeta.js`를 손으로 고치지 않는다.
- `schema.sql`은 통째로 다시 실행한다. 변경은 멱등이다. `CREATE TABLE IF NOT EXISTS`, `ADD COLUMN IF NOT EXISTS`, `CREATE OR REPLACE FUNCTION`, `DROP POLICY IF EXISTS`, `CREATE INDEX IF NOT EXISTS`, `INSERT ... ON CONFLICT DO NOTHING`. `DROP TABLE`은 없다. 시그니처가 바뀌는 함수만 `DROP FUNCTION IF EXISTS`로 그 시그니처를 지운 뒤 만든다.
- 캐시: 이번 태스크에서 바뀐 모듈의 import `?v=`와 `index.html`의 `main.js?v=`를 같은 토큰으로 함께 올린다.
- 태스크 안에서 `npx wrangler deploy`, Supabase SQL 실행, `.dev.vars` 읽기, `git push`를 하지 않는다.
- 테스트는 `node`로 직접 실행한다. `package.json`을 만들지 않는다. `test/cf-stub.mjs`와 `test/plaza.test.mjs` 방식을 따른다. `https://studio.wishboard.workers.dev`를 호출하지 않는다. 테스트는 프로덕션 Supabase에 점령·지급을 쓰지 않는다. 로컬 `wrangler dev`도 프로덕션 DB를 본다.
- 이름표 색은 재질 이름이 `Main`인 메시에만 칠한다.
- 원점은 7번가 × W 45th St. 북쪽은 −Z, 동쪽은 +X. 채널은 `chapel:square`부터 `chapel:square-8`. `CAP`은 50이다.

`tribe.js`:

```js
export function pledge(slot, amount) {
  const n = Math.floor(Number(amount));
  if (n !== 10 && n !== 20 && n !== 50) return null;
  if (!/^(MAIN_(UP|TOP|MID|BOT|LOW)|SUB_[1-4][AB]|STREET_([1-9]|[12]\d|30)|PLOT_([1-9]|1[0-8]))$/.test(String(slot || ''))) return null;
  return { slot: String(slot), amount: n };
}

export function sendCheer(slot, phraseId) {
  const p = Math.floor(Number(phraseId));
  if (p < 1 || p > 12) return null;
  if (!/^(MAIN_|SUB_|STREET_|PLOT_)/.test(String(slot || ''))) return null;
  return { t: 'CHEER', slot: String(slot), p };
}

export function openTribe() {
  return { create(tag) { return { tag: String(tag || '').replace(/^#/, '').slice(0, 16) }; } };
}
```

`schema.sql`에 설계 5.6 네 테이블 DDL을 그대로 넣는다. `profiles.tribe_id`는 5.1 CREATE에 이미 있다.

`pledge_tribe`는 `p_amount`가 10, 20, 50이 아니면 `{ ok:false }`다. 멤버가 아니면 거절한다. 멤버 지갑에서 빼고 `tribe:<id>` 지갑에 같은 금액을 더한다. `tribe_pool`에 행을 남긴다. `coin_ledger` reason은 양쪽에 `sell`이 아니라, 멤버는 음수 `spend`, 소속 지갑은 양수 `spend`로 같은 트랜잭션에 넣어 합이 0이 되게 한다. 새 코인은 없다.

`refund_tribe_week`는 그 `week`의 풀 중 점령에 쓰이지 않은 행만 낸 `actor_id`에게 `amount`를 100% 되돌리고 소속 지갑에서 뺀다. 합은 0이다.

`POST /rt/tribe`에 `tag`가 있으면 id 8자를 만들어 `tribes`와 `tribe_members.role = 'owner'`와 `profiles.tribe_id`를 쓴다. `tag`는 `#[0-9A-Za-z가-힣_]{1,16}`에서 `#`을 뺀 값이고 `blockedText`면 거절한다. `{ id }`만 있으면 그 소속에 `member`로 가입하고 기존 소속이 있으면 거절한다. 응답은 `{ tribe_id, tag }`.

`POST /rt/tribe/pledge`는 `pledge()`와 같은 검증 뒤 `pledge_tribe`를 호출한다.

```sql
CREATE OR REPLACE FUNCTION public.pledge_tribe(p_key TEXT, p_actor_id TEXT, p_slot_id TEXT, p_amount BIGINT, p_week TEXT)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public
AS $$
DECLARE
  v_secret TEXT;
  v_tribe TEXT;
  v_coins BIGINT;
BEGIN
  SELECT key_value INTO v_secret FROM public.app_secrets WHERE key_name = 'FLUSH_KEY';
  IF v_secret IS NULL OR p_key IS DISTINCT FROM v_secret THEN
    RAISE EXCEPTION 'Unauthorized worker key';
  END IF;
  IF p_amount NOT IN (10, 20, 50) THEN
    RETURN jsonb_build_object('ok', false, 'error', 'amount');
  END IF;
  IF p_week !~ '^[0-9]{4}W[0-9]{2}$' THEN
    RETURN jsonb_build_object('ok', false, 'error', 'week');
  END IF;
  SELECT tribe_id INTO v_tribe FROM public.tribe_members WHERE actor_id = p_actor_id;
  IF v_tribe IS NULL THEN
    RETURN jsonb_build_object('ok', false, 'error', 'tribe');
  END IF;
  SELECT coins INTO v_coins FROM public.wallets WHERE actor_id = p_actor_id FOR UPDATE;
  IF COALESCE(v_coins, 0) < p_amount THEN
    RETURN jsonb_build_object('ok', false, 'error', '코인이 부족합니다. 붕어빵을 더 구워보세요!');
  END IF;
  INSERT INTO public.wallets (actor_id, nickname, coins) VALUES ('tribe:' || v_tribe, v_tribe, 0)
  ON CONFLICT (actor_id) DO NOTHING;
  UPDATE public.wallets SET coins = coins - p_amount, updated_at = now() WHERE actor_id = p_actor_id;
  UPDATE public.wallets SET coins = coins + p_amount, updated_at = now() WHERE actor_id = 'tribe:' || v_tribe;
  INSERT INTO public.coin_ledger (actor_id, delta, reason, ref) VALUES
    (p_actor_id, -p_amount, 'spend', p_slot_id),
    ('tribe:' || v_tribe, p_amount, 'spend', p_slot_id);
  INSERT INTO public.tribe_pool (tribe_id, slot_id, actor_id, amount, week)
  VALUES (v_tribe, p_slot_id, p_actor_id, p_amount, p_week);
  RETURN jsonb_build_object('ok', true, 'tribe_id', v_tribe, 'amount', p_amount);
END;
$$;
```

Worker는 `p_week`에 기존 `isoWeek()` 문자열만 넘긴다.

`claim_billboard`의 `p_mode = 'tribe'` 분기는 `tribe_closed`를 제거하고, 지불 계정을 `tribe:<id>`로 본다. `holder_id`는 `'tribe:' || id`, `holder_name`은 `tag`다. 환불은 그 지갑으로 간다. 개인 지갑은 이 모드에서 차감하지 않는다. 메인 타워는 `auction_closed` 규칙을 그대로 탄다. S급이면 `p1-moderation`의 pending 분기를 탄다. 승인 시 지불 계정은 리뷰에 저장된 `tribe:` id다.

멤버·KST 하루 점수는 응원 1, 불 켜기 1, 점령 5, 상한 7이다. Room `ag` 키 `ts`에 모았다가 flush 때 `tribe_scores`에 더한다. 멤버·하루 1회 이하로 RPC를 호출한다. `week`는 `isoWeek()`.

`relight_billboard`는 `holder_id`가 `tribe:`이고 호출자가 `tribe_members`에 있으면 보유자 본인이 아니어도 통과한다. 코인은 여전히 움직이지 않는다.
