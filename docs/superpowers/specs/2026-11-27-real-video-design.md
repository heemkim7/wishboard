# 실사 축하 영상 (설계, 2026-11-27)

주인이 정한 것(2026-11-27 대화): AI로 만든 타임스퀘어풍 바탕 영상 7개(`video/plate-01`~`07`, 9:16, 초록 화면)에 선물 전광판을 합성한 실사 영상을 앱에서 만든다. **R2 없이** 간다: 바탕 영상은 압축해서 앱 정적 파일로 두고, 합성은 사용자 기기에서 하고, 결과 영상은 기기에 저장하거나 바로 공유한다(서버에 올리지 않는다). 오른쪽 아래 작은 "AI 합성" 표시를 남긴다. 음악은 코드로 합성한 오리지널(내용별). 무료 시즌에는 무료.

바탕: 샘플 도구 `tools/plates/`(`track.py` 모서리 추적, `card.py` 카드, `scene.py`/`composite.py` 합성, `music.py` 음악), 샘플 결과 `out/2026-11-27/plates/sample-0N-*-final.mp4`.

## 1. 사용자 흐름

1. 선물 전광판 주인 화면 `/g/<id>`의 영상 칸에 **"🎬 실사 축하 영상"** 카드. 장면 7개의 작은 미리보기(정지 사진)와 이름: 정면 밤, 타워, 비 오는 밤, 연말 군중, 내 손 휴대폰, 코너 입체, 블루아워.
2. 장면을 누르면 그 장면만 받는다(약 5~8MB, 진행 표시). 받는 동안 다른 장면을 고를 수 있다.
3. "만들기"를 누르면 10초 영상을 실시간으로 만든다(진행 막대, 화면을 닫거나 숨기면 멈추고 다시 하기). 그 선물의 받는 사람·무슨 날·한마디·보내는 사람·색으로 카드를 그린다. 음악은 무슨 날에 맞춘 곡.
4. 끝나면 미리보기 재생, **저장**(파일), **공유**(휴대폰 공유 창에 파일로, 되는 기기만). 파일 이름 `wishboard-<받는 사람>-<장면>.mp4`.
5. 만들 수 없는 기기(녹화 미지원, WebGL 없음)는 이유를 말하고 기존 2D 영상을 권한다.

받는 사람 페이지에는 이번에 넣지 않는다(다음 단계).

## 2. 자산 (한 번 준비, `tools/plates/`가 만든다)

- `assets/plates/plate-0N.mp4`: 1080×1920(7번은 맞춰 늘림), 24fps, 10.04초, H.264 + 원래 거리 소리(AAC 낮은 비트레이트), **파일당 8MB 이하**(Workers 정적 파일 25MiB 한도 안, 휴대폰 내려받기 고려). `faststart`.
- `assets/plates/plate-0N.json`: 프레임별 화면 모서리(장면마다 화면 하나 이상: 5번은 전광판+휴대폰 둘, 6번은 L자 두 면과 접힌 선, 1·4번은 작은 휴대폰 화면들), 카드 배치 종류(card/banner/wide/corner), 바닥 초록 반사 시작 높이 등 합성에 필요한 값. 크기는 장면당 수십 KB 안.
- `assets/plates/plate-0N.jpg`: 미리보기 정지 사진(작게, 30KB 안팎).
- `assets/plates/music-<occ>.m4a`: 무슨 날 6가지(생일 `bday`, 기념일, 합격, 응원, 그냥, 고마움 — 키는 `giftrules.js` `OCCASIONS`와 같게) 각 10.04초, 번쩍(1.5초)에 맞춘 "짠!", −19 LUFS 안팎, 각 200KB 안. 생일은 지금 곡, 나머지 다섯은 `music.py`에 새로 짓는다.
- 서비스워커가 미리 담지 않는다(필요할 때만 받는다). 정적 파일 캐시는 기존 규칙.

## 3. 기기 안 합성

- 새 모듈 `realvideo.js`(이름은 구현이 정해도 된다): 바탕 영상 `<video>`를 WebGL 텍스처로 받아, 프레임 번호의 모서리로 호모그래피를 계산해 카드 텍스처를 그린다.
- **초록 키는 셰이더에서**: 바탕 영상의 초록 픽셀 자리에만 카드를 보이고, 초록이 아닌 것(손가락, 눈, 사람)은 앞에 남는다. 테두리 초록 번짐 제거, 바닥 초록 반사는 카드 평균색으로 바꾸기.
- 진짜 LED처럼: 은은한 점무늬, 밝기 맞춤, 테두리 빛 번짐(작은 블룸), 휴대폰 화면은 점무늬 없이 유리 반사.
- 카드: 샘플의 `card.py` 배치(card/banner/wide/corner)와 연출(0~1.4초 대기 반짝임, 1.5초 번쩍, 차례로 등장, 꽃가루)을 캔버스 2D로 옮긴다. 선물 테마 색과 문구를 쓰고, 긴 이름·한마디는 줄을 바꾸거나 줄인다. 이모지 없이도 배지가 보여야 한다.
- 6번(코너) 선물 상자 튀어나오기는 샘플처럼 넣되, 무거우면 빼도 된다(정적 L자 감싸기는 필수).
- 오른쪽 아래 "AI 합성"(1080 기준 글자 높이 24px 안팎, 흰색 70%, 그림자).
- 녹화: 기존 `giftfilm.js` `recordCanvas` 방식(MediaRecorder, MP4 우선)으로 캔버스 + 오디오(바탕 소리 −34 LUFS 수준으로 낮춤 + 음악)를 담는다. 바탕 영상은 처음부터 끝까지 실시간 재생에 맞춰 그린다. 기기가 느리면 720×1280으로 낮춘다. 녹화 중 화면이 숨으면 멈추고 다시 하기.
- 소리 섞기: WebAudio로 바탕 영상 소리와 음악 파일을 정해진 크기로 섞어 녹화 스트림에 넣는다. 번쩍 순간 거리 소리를 잠깐 올리는 것은 샘플과 같게.
