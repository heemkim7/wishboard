# 게임 문구 정리 목록 (비게임 전환, 2026-11-23)

비게임 전환(`docs/non-game-plan-2026-11-22.md`)에 맞춰 화면에 남은 "게임" 문구를 찾은 결과다. 이번 작업(약관·처리방침·문구 담당)에서 바꾼 것과, 다른 작업(코인 이름 바꾸기, 놀이 보상 끄기, 점령 → 응원 목표)이 합쳐진 뒤 리드가 마무리할 것을 나눠 적는다.

찾는 법: 주석을 빼고 한글이 들어간 문자열 가운데 `K-점령전 점령 땅따먹 게임 코인 플레이 빼앗 추첨 복권 로또 붕어빵 입찰 되찾 분양 인수 증축 장악 운임 별똥별 복주머니 황금 링 하이파이브 댄스`가 있는 줄. 줄 번호는 `d6b9251` 위에 이 작업을 얹은 상태 기준이라, 다른 브랜치가 합쳐지면 어긋난다. 합친 뒤 다시 찾으려면 같은 단어로 `rg`를 돌린다.

## 3. 남은 것 (합친 뒤 리드가 마무리)

분류: **C** 코인 문구(코인 이름 바꾸는 작업 몫), **L** 추첨(내림), **M** 보상 붙은 놀이(보상을 빼거나 내림), **O** 점령·빼앗기·입찰·분양(응원 목표형 명당과 기간제 전광판으로 바뀜), **G** 그 밖의 '게임'·'플레이' 낱말.

- C·L·M·O는 기능이 바뀌면서 문구가 같이 바뀌거나 사라질 것이라 이번에 건드리지 않았다. 합친 뒤 이 표를 다시 돌려 남은 줄만 본다.
- G 가운데 바로 바꿀 수 있는 것: `main.js` 링크 나감 안내의 `'게임 밖'` → `'광장 밖'`, `ui.js` 놀이 안내의 "이모지 4번은 게임이 아니에요"(놀이를 남기면 문구를 새로), `recap.js`·`league.js`의 주간 지출 문구(리그가 응원 순위로 바뀌면 다시 씀), `opsrules.js` 문의 분류 `계정·코인` → `계정·포인트`.
- 3D 화면 글자(`ts3d/screens.js`의 "코인을 모아 이 화면을 점령하세요", `ts3d/art.js` 붕어빵 간판의 "+6 코인", 분양 간판)는 광장 안에서 크게 보인다. 게임위 첨부 영상을 찍기 전에 바꿔야 한다.
- 서버가 돌려주는 오류 문구(`worker.js`, `balance.js`)도 화면에 그대로 뜬다.

### 다시 볼 때 같이 볼 것: 약관이 약속한 것

`legal.js`(시행 2026-11-23)는 전환 뒤의 서비스를 적었다. 아래가 코드와 맞지 않으면 배포 전에 문구나 코드를 고친다.

1. 조작하는 놀이·추첨·확률로 주는 보상이 하나도 없다(붕어빵, 댄스, 택시 운임, 별똥별, 황금 링, 하이파이브, 바닥 동전, 복주머니, 5분 추첨).
2. 응원 포인트는 팔지 않고, 보내기·모금이 없다(지금 코드에는 '광고주에게 코인 보내기'와 소속 모금이 있다).
3. 다른 사람의 전광판을 포인트로 빼앗는 기능이 없고, 일반 전광판은 기간이 끝나면 내려간다. 명당은 공개 규칙(응원 목표, 참여율, 기념일)으로만 돌아간다.
