# 다음 단계 (2026-11-28)

예상 효과, 개발 크기, 운영 비용으로 다시 매겼다. 모든 항목을 할 필요는 없다.

## P0 (이번에 만듦, 배포 전)

첫 화면 두 행동, 내 전광판 모드, 사랑·졸업·승진, 3D 없는 공유 카드 페이지, `/discover`, 정직한 가격표와 갈래 기록, 계정에 남겨 두기, 카드 이미지 저장, 주문·결제(꺼짐, PortOne V2 시험·모의), 유료 혜택 전달(12시간·깔끔한 영상·메인 타워 지정), 운영 화면 주문·매출, WAU, 운영자·시험 트래픽 제외, 공개 전 선물 내용 숨김(데이터까지).

## P2 (매출 확대)

프리미엄 템플릿·애니메이션, 개인 전광판 고급 디자인, 랜드마크별 자리 상품(시부야 등은 에셋·OSM 원칙 검토), 반복 구매 상품, 구독(수요 확인 뒤), 해외 결제, 기업 광고 재개.

## 보류와 이유

- 광장 HUD를 다섯 갈래 메뉴로 바꾸기: 시즌 숫자를 본 뒤(구조 변경 위험).
- 댓글: 자유 글 채팅 없음 원칙. 롤링페이퍼와 답장 전광판이 그 자리.
- 경매·돈 순위·금액 공개: 비게임 원칙과 평판.
- 포인트 현금화: 게임물 판단과 비용.
