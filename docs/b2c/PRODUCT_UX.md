# 제품 UX (2026-11-28)

## 첫 화면 (`index.html` 부팅 카드)

3D 도시가 지어지기 전에 정적 HTML로 바로 보인다.

1. 제목(가장 먼저): **누구나 무료로 전광판을 만들고 공유할 수 있어요** (2026-11-28, 무료 우선)
2. **누군가에게 선물하기** → `/gift` (선 아이콘, 주 버튼)
3. **내 전광판 만들기** → `/gift?me=1`
4. 작은 링크 두 개가 한 줄: **다른 사람들의 전광판 둘러보기** → `/discover`, 흐린 **준비 중인 기능** → `/discover#soon`
5. **3D 광장 둘러보기** (예전 `입장하기`, 닉네임 칸과 함께)

부팅 카드에는 가격·카드·"출시 예정" 낱말이 없다. 선물·공유·감상은 3D 없이 된다. 지시문의 다섯 갈래 메뉴(WORLD·DISCOVER·GIFT·CREATE·MY)는 3D 밖 페이지에서 링크로 이어 두고, 광장 HUD는 바꾸지 않았다(시즌 숫자를 본 뒤 정한다).

## 선물 전광판 (`/gift` → `/g/<id>`)

1. 무슨 날: 생일, 기념일, 사랑, 합격, 졸업·승진, 응원, 그냥, 고마움 (`OCCASIONS`)
2. 받는 사람 이름(12자), 한마디(40자, 선택), 보내는 사람(선택). 전화번호·주소는 받지 않는다.
3. 언제: 오늘 지금 / 오늘·다른 날 9·12·15·18시(30일 안)
4. 색 6가지, 입력하는 동안 미리보기
5. 무료로 걸기 → 주인 화면 `/g/<id>`
6. 주인 화면: 링크 보내기, 축하 영상 하나(실사, 안 되는 기기는 15초 영상), 더 보기(메인 타워에 올리기: 친구 10곳·포인트 2,000, 둘러보기에 보이기(기본 꺼짐), 카드 이미지 저장, 지금까지 숫자, 받는 사람 화면, 지우기). 가격표는 `PAY_ON=1`일 때만 보인다(지금 꺼짐, 가격 3단계는 숨김).
7. **준비 중인 기능(출시 예정)**: 방금 건 주인 화면에서는 맨 아래, 나중에 다시 열면 더 보기 맨 아래에 한 번만. 만들기 단계와 받는 사람 화면에는 없다. 아래 "출시 예정" 참고.

**받는 사람** (`/g/<id>`, 가입·3D 없이): 그날 전에는 D-n과 하트(숫자 없이), 롤링페이퍼 쓰기, 점등식 같이 보기. 그날에는 영상 먼저 → 메시지 → 하트·공유·영상 저장·답장 전광판·나도 걸어 주기 → 반응 뒤 "계정에 남겨 두기". 공개 전에는 메시지가 주인 외에 나가지 않는다.

## 개인 전광판 (`/gift?me=1`)

같은 화면에서 "내 전광판" 모드: 이름(닉네임으로 채움), 종류 칩(이름 걸기·다짐·작품·채널·특별한 순간: 예시 문구만 넣음), 보내는 사람 칸 없음. 카드는 "by 이름", 롤링페이퍼는 "응원 메시지", 방문자 버튼은 "…님에게 응원 전광판 걸기". 1분 안에 만들 수 있게 입력은 두 칸이 필수다.

사진 업로드는 아직 없다: 관리자 승인과 저장소(R2)가 먼저 필요하다(로드맵).

## 둘러보기 (`/discover`)

3D 없이, 캐시된 `/rt/world`와 `/rt/wishes`만 읽는다(방문마다 서버 저장소 호출 없음). 탭: 지금 인기, 새로 걸린, 생일, 응원, 개인 전광판, 소원. 인기는 정렬만, 순위 번호·숫자 없음. 행동: 하트(소원·선물), 공유, 3D에서 보기, 나도 만들기. 선물은 공개된 뒤 광장에 걸린 것 가운데 **주인이 켠 것만**. 실제 콘텐츠가 적을 때만 "예시 · WISH BOARD" 계절 카드를 따로 묶어 보이고 세지 않는다.

## 출시 예정 (`soonrules.js`, `soon.js`, 2026-11-28)

사업자 등록 전이라 서비스는 무료다. 나중에 생길 수 있는 기능을 "출시 예정"으로만 보여 주고 관심을 잰다. 팔지 않는다: 가격·날짜·구매 버튼·알림 약속이 없고, 지금 무료인 기능(실사 축하 영상과 입체 상자, 카드 이미지, 15초 영상, 메인 타워 1분, 만들기와 공유)은 넣지 않는다.

| 기능 | 한 줄 |
| --- | --- |
| 특별한 전광판 | 더 공들인 디자인, 전광판 위의 사진과 영상, 더 화려한 움직임을 고를 수 있게 준비하고 있어요. |
| 선물 특별 연출·선물 보관함 | 선물을 열 때 나오는 특별한 연출과, 보내고 받은 선물을 한곳에 모아 두는 보관함이에요. |
| 오래 남기기 | 7일이 지나도 기념 페이지와 기록을 남겨 두고, 디지털 기념품으로 간직하는 기능이에요. |
| 특별한 자리 | 타임스퀘어 밖의 다른 랜드마크 공간, 행사 때만 열리는 공간에 거는 기능이에요. |

- 머리말 "준비 중인 기능이에요. 관심을 눌러 주시면 무엇부터 만들지 정하는 데 써요." 그 아래 "지금 되는 전광판 만들기와 공유, 축하 영상은 그대로 무료예요."
- 카드: 선 아이콘(호박색), 이름, 작은 회색 "출시 예정" 표, 한 줄, 버튼 "이 기능에 관심 있어요". 누르면 "관심 담음"(눌린 상태, 다시 못 누름)과 "관심을 담았어요. 고마워요!". 서버가 붐비면 "지금은 붐벼서 담지 못했어요. 잠시 뒤에 다시 눌러 주세요."로 다시 누를 수 있다. 되돌리기는 없다.
- 보이는 곳(이것만): 걸고 난 선물 주인 화면과 내 전광판 주인 화면(맨 아래), 다시 연 주인 화면의 더 보기, `/discover` 맨 아래(`#soon`, 부팅 카드의 작은 링크가 여기로), 광장에서 전광판을 건 뒤 나오는 막대의 작은 글자 링크 "준비 중인 기능 보기"가 여는 시트. 팝업으로 띄우지 않는다.

## 공유와 받는 경험

- 선물: `/g/<id>`, og 카드 1200×630(공개 전에는 예고 카드), 휴대폰 공유 창 → 복사.
- 광장 전광판 `/rt/card/<칸>`, 소원 `/rt/w/<id>`: 이제 3D로 바로 넘기지 않고 카드 페이지(3D 광장에서 보기, 공유하기, 나도 만들기, 친구 N명).
- 카카오 SDK는 쓰지 않는다(카카오 개발자 정책). 휴대폰 공유 창과 og 태그로 카톡에 보낸다.
- 링크로 온 친구가 반응하면 보낸 사람에게 공유 보상(하루 30명, 50/20/10).

## 3D 광장의 역할

특별한 경험(점등식, 메인 타워 1분, 실사 영상의 바탕, 같이 춤추기, 사진). 바로 가기: `/?gb=<id>`(선물), `/?focus=<칸>`(전광판), 내 전광판 빛기둥. 휴대폰 자동 둘러보기와 자리별 미리보기는 로드맵.

## 카피 원칙

선물과 자기표현이 먼저, 광고판 임대처럼 들리지 않게. 늘 "가상". 무료가 먼저 읽히게: 지금 되는 기능을 유료처럼 보이게 쓰지 않는다. 결제가 열리면 결제 전 가격·혜택·환불 규칙을 한 화면에.
