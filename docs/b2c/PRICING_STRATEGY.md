# 가격 전략 (2026-11-28)

## 지금: 무료 우선, 유료는 "출시 예정"으로만 (2026-11-28, 주인 결정)

- 사업자 등록 전이라 아무것도 팔지 않는다. 서비스는 무료이고, 부팅 카드 첫 줄이 "누구나 무료로 전광판을 만들고 공유할 수 있어요"다.
- 결제 코드는 그대로 두고 `PAY_ON`(꺼짐) 뒤에 있다. 아래 가격표(3,900 / 7,900 / 14,900)는 `PAY_ON=1`이 아니면 어디에도 보이지 않고, 그 비컨(`ladder`, `pick`, `notify`)도 나가지 않는다.
- 수요는 "출시 예정" 카드 네 장으로 잰다(`soonrules.js`): 특별한 전광판, 선물 특별 연출·선물 보관함, 오래 남기기, 특별한 자리. 가격·날짜·구매 버튼·알림 약속이 없고, 지금 무료인 기능(실사 영상과 입체 상자, 카드 이미지, 15초 영상, 메인 타워 1분)은 넣지 않았다. 숫자는 `GROWTH_ANALYTICS.md`의 "출시 예정 관심".
- 아래 가격표와 실험은 결제를 열 때를 위한 준비다. 무엇부터 열지는 관심 등록 순위를 보고 정한다.

## 가격 실험

- 갈래는 Worker 변수 `GIFT_ARMS`로 정한다(없으면 한 갈래 A). 보드마다 갈래가 정해지고(`ladderArm`), 주인 화면과 주문이 같은 값을 쓴다. 결제 전 가격은 늘 화면에 보인다.
- 기록: `ladder:<갈래>:<g|me>`(가격표를 본 수), `pick:<단>:<갈래>:<종류>:<가격>`(고른 수), `notify:…`(알림 신청), 주문의 `arm`·`price`(결제 성공). **고름과 결제 성공을 따로 센다.**
- 실험 조건과 대상(보드 id로 나눔)은 변수와 이 문서에 적는다. 표본이 작을 때(한 갈래 수십 건 미만) 비율을 결론으로 쓰지 않는다.

## 원가와 마진 (1건 기준)

| 항목 | 값 | 근거 |
| --- | --- | --- |
| PG 수수료 | 약 3.2%(PortOne+KCP) ~ 3.4%(토스페이먼츠) + 부가세 | PG 공시. 3,900원이면 약 140원 |
| 부가세 | 가격의 1/11 | 가격은 부가세 포함 |
| 영상 렌더 | 0원 | 사용자 기기에서 합성 |
| 저장소 | 0원(R2 꺼짐), 켜면 10GB까지 무료 | Cloudflare 공시 |
| 서버(Workers·DO) | 무료 범위 안. 초과 단가는 모름 | 주문 1건에 DO 호출 약 12번 |
| 검수 | 지금 0(사진 없음). 사진 도입 시 건당 사람 시간 | 모름 |
| 환불 | 게시 전 전액, 게시 뒤 원칙적으로 불가(약관 초안) | 법무 확인 필요 |

대략: 3,900원 → 부가세 뒤 3,545원, PG 뒤 약 3,400원. 7,900원 → 약 6,900원. 14,900원 → 약 13,000원. 나머지 원가는 거의 0이라 매출총이익률이 높다. 진짜 변수는 결제율과 환불률이다.

## 정하지 않은 것

- 해외 가격(2.99~19.99달러, 전략 보고서) — 영어판과 해외 결제(판매 대행) 뒤.
- 사진·특별한 디자인 단 — 사진 검수와 R2 뒤("특별한 전광판" 관심을 먼저 본다).
- 오래 남기기(7일 넘는 기념 페이지) — 보관 비용과 "오래 남기기" 관심을 본 뒤.
- 구독 — 반복 구매가 확인된 뒤.
- 포인트를 돈 상품에 섞지 않는다(포인트 2,000으로 여는 메인 타워 1분은 무료 길로 남는다).
