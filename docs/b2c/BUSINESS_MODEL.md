# 사업 모델 (2026-11-28)

바깥 검토(ChatGPT 'B2C 사업모델 구축' 지시문)를 지금 코드와 대조해 정한 것이다. 기업 광고(`AD_1~5`, `/ads`)는 생태계가 커진 뒤로 미룬다.

## 한 줄

**당신의 특별한 순간을, 가상 타임스퀘어 전광판에.** 일반 사용자가 누군가를 축하하거나(선물) 자기 순간을 남기려고(개인) 전광판을 만들고, 공유하고, 더 오래·더 깔끔하게·메인 타워에 걸고 싶을 때 한 번씩 돈을 낸다.

## 두 상품, 하나의 엔진

| | A. 선물 전광판 (GIFT) | B. 개인 전광판 (PERSONAL, "내 전광판") |
| --- | --- | --- |
| 누구를 위해 | 다른 사람(생일, 기념일, 사랑, 고마움, 합격, 졸업·승진, 응원, 그냥) | 나(이름 걸기, 다짐, 작품·채널, 특별한 순간) |
| 만드는 곳 | `/gift` | `/gift?me=1` (같은 엔진, 무슨 날 `me`) |
| 카드 | "To. 이름" | "by 이름" |
| 받는 쪽 | 받는 사람 페이지 `/g/<id>`, 롤링페이퍼, 하트, 답장 전광판 | 같은 페이지, "응원 메시지", "응원 전광판 걸기" |
| 구매 동기 | 그 사람에게 특별한 경험을 선물하고 같이 보기 | "내가 타임스퀘어에 나왔다"는 기록과 자랑 |

내부적으로는 둘 다 선물 저장소(`giftsrv.js`, Meter DO `gift`)의 같은 보드다. 차이는 무슨 날 키(`me`)와 문구뿐이라 만들기·게시·공유·영상·메인 타워·결제가 한 번에 두 상품에 붙는다. 광장의 72시간 일반 전광판(`balance.js`)은 또 하나의 개인 표현 자리로 그대로 둔다.

## 무료와 유료

**무료가 하는 일** (참여를 막지 않는다): 광장 화면 6시간, 15초 축하 영상과 실사 축하 영상(워터마크), 받는 사람 페이지 7일, 롤링페이퍼, 하트, 답장, 공유, 친구 응원 10명이 모이면 메인 타워 축하 1분, 둘러보기, 3D 광장.

**유료가 더하는 경험** (결제가 열리면, `giftrules.js` TIERS):

| 단 | 가격(부가세 포함) | 더하는 것 |
| --- | --- | --- |
| 오래 걸기 | 3,900원 | 광장 화면 12시간, 받는 사람 페이지 광고 없음 |
| 축하 영상 세트 | 7,900원 | 오래 걸기 + 워터마크 없는 15초 영상과 실사 영상("AI 합성" 표시는 남음) |
| 메인 타워 주인공 | 14,900원 | 축하 영상 세트 + 메인 타워 축하 1분을 원하는 시각에 바로 지정(친구 응원 없이, 그날 30자리 안) |

크기 차이가 아니라 **시간(더 오래), 결과물(깔끔한 영상), 자리와 순간(메인 타워 지정 1분)**의 차이다. 노출량이나 광고 효과는 팔지 않는다.

## 지키는 것

- 비게임: 포인트는 팔지 않고, 넘길 수 없고, 현금이 되지 않는다. 순위 번호, 경쟁 보상, 추첨이 없다. 돈으로 이기는 구조가 없다(메인 타워 1분은 정가·선착순, 하루 30자리).
- 가상 고지: 실제 타임스퀘어 송출이 아니다. 실사 영상에는 "AI 합성".
- 깜짝 선물: 공개 전에는 받는 사람 외에 내용이 나가지 않는다.
- 1회 결제 중심. 구독은 반복 구매가 확인된 뒤.

## 수익 구조

- 매출 = 유료 단 판매(1회). 원가 = PG 수수료(약 3.2~3.4% + 부가세), Cloudflare(무료 범위 안, 초과는 모름), 검수 시간(사진 도입 시). 영상은 사용자 기기에서 만들어 서버 원가가 거의 없다.
- 주문·매출은 `ordersrv.js`(Meter DO `order`)와 운영 화면 "🧾 주문·매출"에서 본다. 결제는 `PAY_ON=1` 전까지 꺼져 있다.

## 다섯 질문에 대한 지금의 답

1. **왜 방문하나**: 친구에게 받은 전광판 링크, 내가 만든 전광판의 반응, 둘러보기의 새 전광판.
2. **왜 내 전광판을 만드나**: 이름·다짐·작품을 가상 랜드마크에 걸고 1080p 실사 영상으로 자랑하려고.
3. **왜 선물하나**: 카톡 메시지보다 큰 경험(광장 점등, 친구들의 롤링페이퍼, 메인 타워 1분, 실사 영상)을 주려고.
4. **받은 사람은 왜 다시 오나**: 답장 전광판, "나도 걸어 주기", 롤링페이퍼가 열리는 날, 계정에 남겨 두기.
5. **왜 유료를 고르나**: 더 오래, 워터마크 없이, 원하는 시각에 메인 타워. 무료로 이미 좋은 것을 먼저 겪은 뒤에.

흐름: 선물 → 받는 사람 방문 → 감상 → 반응·답장 → 새 전광판 → 공유 → 새 사용자 → 재구매. 개인: 내 전광판 → 게시 → SNS 공유 → 다른 사람의 반응 → 기록 → 다음 전광판.
